# MediVerse Mobile & Web Frontend

MediVerse is a smart cross-platform healthcare & emergency assistance application built with Flutter (Dart).

## Features
- **Google / Gmail Authentication**: Direct sign-in with official Google branding and JWT token management.
- **Doctor Discovery & Credentials View**: Search doctors by specialty, view doctor details and **4 verified certificates/documents** (Medical Council License, DM Diploma, Clinical Experience Letter, Healthcare Quality Accreditation).
- **Consultation Slot Booking**: Interactive appointment scheduling.
- **Blood Donor Matching & SOS Broadcast**: Real-time donor listing, blood group filtering, and 1-click Emergency SOS alert.
- **Clinic Locator & Admin Panel**: Hospital routing and system metrics monitoring.

## Deployed Backend Connection
The frontend connects directly to the deployed REST API backend at:
`https://backend-blod.onrender.com/api`

## Getting Started
```bash
# Get dependencies
flutter pub get

# Run on Chrome Web
flutter run -d chrome

# Run on Android / iOS
flutter run
```
